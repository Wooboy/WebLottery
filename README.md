# 網頁抽獎系統

這是一個基於 **Vue 3** 開發的純前端抽獎應用程式。具備高度自定義的獎項設定、流暢的抽獎動畫、以及完整的資料持久化功能，適合各類年會、春酒或活動場合使用。

## 🚀 核心特色

- **純前端運作**：無需後端資料庫，所有資料皆儲存在瀏覽器的 `LocalStorage`，重新整理頁面不丟失進度。
- **靈活抽獎模式**：
  - **連續單抽**：啟動亂數跳動後，每按一次空白鍵抽出一位中獎者，動畫持續進行不中斷，直到獎項抽滿為止。
  - **一次抽完**：按下空白鍵後直接揭曉該獎項剩餘的所有名額。
- **七種抽獎動畫（每個獎項可各自設定）**：
  | 樣式 | 操作方式 |
  | :--- | :--- |
  | 🎲 經典跳字 | 第一下開始跳動；連續單抽每按一下抽出一位（動畫不停），一次抽完則一次揭曉 |
  | 🎰 老虎機 | 員編轉輪：轉輪數 = 員編長度，每輪在 A–Z、0–9 間轉動。第一下轉動，第二下由左到右依序停在中獎者員編上（每停一碼顯示還有幾人符合），全部停下才帶出人名。每次一位，一次抽完時自動連續轉到抽滿 |
  | 🎡 幸運轉盤 | 第一下轉動，第二下停止；最多 12 格，中獎者一定在盤面上。一次抽完時自動連續轉到抽滿 |
  | 🃏 選堆 | 攤開所有可抽人員 → 蓋牌洗牌、平均分成 3～5 堆 → 由老闆點選（或按數字鍵）挑一堆，其餘淘汰；重複分堆直到剩少量牌，再一張張攤開讓老闆選，選中即中獎，其他牌隨後翻開。約 3 輪內選出，每局抽一位 |
  | 🃏 翻牌 | 第一下發牌，來賓 / 主持人點選卡牌翻開，或按鍵隨機翻牌（一次抽完則一次翻開全部名額） |
  | ⏳ 倒數揭曉 | 按一下即倒數 3、2、1，名字逐字出現（多人時依序跳出） |
  | 🎱 扭蛋機 | 按一下扭蛋機搖晃、掉出扭蛋並打開揭曉。一次抽完時自動連續扭到抽滿 |
- **抽獎動畫預覽**：設定頁每個獎項的「動畫樣式」旁有「👁 預覽」按鈕，以該獎項的動畫、名額與抽獎模式模擬抽獎（可在預覽中直接切換樣式比較），結果不會寫入中獎紀錄。使用目前參與名單；尚未輸入名單時使用 30 位示範人員。
- **現場效果**：中獎彩帶特效、合成音效（滾動聲、鼓聲、中獎音效，不需音檔），可在設定頁分別關閉。
- **簡報筆 / 鍵盤操作**：
  | 按鍵 | 功能 |
  | :--- | :--- |
  | 空白鍵、Enter | 抽獎（開始 / 停止 / 下一步），僅抽獎模式中有效 |
  | PageUp / PageDown | 上一個 / 下一個獎項，僅抽獎模式中有效 |
  | Esc | 離開抽獎模式 |
- **以 ID 識別參與人員**：名單每行「ID,顯示名稱」，ID 建議用員工編號。排除已中獎者一律看 ID，同名不同人不會互相影響；畫面顯示名稱，中獎清單與匯出 CSV 同時列出 ID。
- **名單鎖定與打亂**：名單框右上角「🔀 打亂順序」以安全亂數重排名單；一旦開始抽獎（有任何中獎紀錄）名單即鎖定，需按「🧹 清空中獎名單」後才能修改或打亂。
- **重複中獎設定（每個獎項獨立）**：
  - **不允許重複**（預設）：自動排除已中過其他「不允許重複」獎項的人。
  - **允許重複**：從全部名單抽選，已中過其他獎項的人也可再中（適合加碼獎、紅包）；中過此類獎項的人，也不影響其他獎項的抽獎資格。
  - 不論哪一種，同一獎項內的多個名額都不會抽到同一人。
- **視覺美化設計**：
  - **玻璃擬態 (Glassmorphism)**：現代感透明模糊介面。
  - **五大色系切換**：紅、黑、藍、綠、金。底色固定深色，主題色只用於點綴（光暈、邊框、轉盤、牌背、扭蛋機身）；金色保留給中獎者。
  - **抽獎畫面三段式版面**：上方「獎項＋獎品＋剩餘名額」、中間抽獎動畫、下方「已中獎名單（名字＋ID）＋按鍵提示」。
  - **兩種模式**：平時為「⚙️ 設定 / 🏆 中獎清單」畫面（上方選單）；按右上角「▶ 開始抽獎（全螢幕）」進入全螢幕抽獎模式（不提供快捷鍵，避免輸入名單時誤觸），畫面只保留抽獎內容。離開全螢幕即回到原本畫面。瀏覽器不允許全螢幕時，會以視窗模式抽獎（按 Esc 離開）。
- **資料匯入/匯出**：
  - 支援 **CSV 批次匯入獎項**（包含名稱、獎品、數量、背景圖）。
  - 提供 **CSV 中獎名單匯出**（包含抽出時間戳）。
  - **設定檔匯出 / 匯入（JSON）**：參與名單、獎項與系統設定可整份匯出，在個人電腦設定好後帶到會場電腦匯入。

## 📂 檔案架構

```text
/
├── index.html          # 頁面結構與 Vue 模板
├── src/
│   ├── main.js         # 狀態管理、抽獎引擎、鍵盤 / 全螢幕
│   ├── style.css       # Tailwind 指令與自定義樣式
│   ├── lib/            # 安全亂數、名單解析、音效合成、彩帶特效
│   └── stages/         # 七種抽獎動畫元件（*Stage.vue）
├── vite.config.ts      # Vite 設定（輸出單一 HTML 檔）
├── tailwind.config.js
└── postcss.config.js
```

## 🛠️ 安裝與使用

1. **建置（需 Node.js 20.19+ / 22.12+）**：
   ```bash
   npm install
   npm run build
   ```
   產出 `dist/index.html` 單一檔案，Vue 與 Tailwind 皆已內嵌，**不需網路、不需伺服器**，複製到活動電腦後直接以瀏覽器開啟即可。
   開發時可用 `npm run dev` 啟動即時預覽。
2. **名單輸入**：
   - 開啟後預設即為 **⚙️ 設定** 頁面。
   - 在左側「參與人員名單」貼上名單，每行「ID,顯示名稱」，例如：
     ```text
     E001,王小明
     E002,李大華
     E003,王小明
     ```
   - 可用半形逗號、全形逗號或 Tab 分隔（可直接從 Excel 複製「員編、姓名」兩欄貼上）；第一行若是「員編,姓名」等標題列會自動略過。
   - 有獎項使用「老虎機」時，請在名單上方設定「員編長度」（3～5 碼），名單中每個 ID 都必須是這個長度的英數字。
   - 名單框左側有行號。缺少逗號、缺少名稱或 ID 重複時，該行行號會標紅，名單框下方列出錯誤行（點選即跳到該行），修正前無法開始抽獎。
   - 可按「🔀 打亂順序」打亂名單（抽獎本身已是均勻隨機，與名單順序無關；打亂主要影響畫面上的排列）。
3. **設定獎項**：
   - 手動在表格中新增獎項，或準備一個 CSV 檔案進行匯入。
   - 獎項數量 > 1 時，可選擇「連續單抽」或「一次抽完」模式。
   - 勾選「允許重複中獎」，該獎項會從全部名單抽選。
   - 在「動畫樣式」選擇該獎項的抽獎玩法，按「👁 預覽」可先模擬一次（空白鍵 / Enter 或「▶ 模擬按下空白鍵」操作，Esc 關閉）。
   - **在其他電腦準備設定**：在設定頁「💾 設定檔匯出 / 匯入」按「⬇️ 匯出設定檔」，會下載 `抽獎設定_日期-時間.json`（含參與名單、獎項、色系 / 音效 / 員編長度等設定，不含中獎紀錄）。到會場電腦開啟 `index.html` 後按「⬆️ 匯入設定檔」選取該檔案即可；匯入會覆蓋目前的名單與獎項，並清空中獎紀錄（匯入前會再確認）。獎項背景圖若用本機路徑，需一併複製圖片並保持相同路徑。
   - **獎項背景圖**（選填，全螢幕抽獎時以淡化方式鋪在背景）：可填網址（`https://…`）、相對於 `index.html` 的路徑（例如 `img/頭獎.jpg`），或直接貼上 Windows 路徑（例如 `C:\圖片\頭獎.jpg`，檔案總管「複製路徑」帶的引號也可以）。欄位左側會顯示縮圖，讀取失敗會提示紅字。
   - 刪除獎項（✕）前會再確認一次。
4. **開始抽獎**：
   - 按右上角 **▶ 開始抽獎（全螢幕）** 進入全螢幕抽獎模式。
   - 使用畫面上方的 **❮ / ❯** 按鈕或 **PageUp / PageDown** 切換要抽的獎項（抽獎進行中會鎖定）。
   - 按下 **[ 空白鍵 ] 或 [ Enter ]** 啟動 / 揭曉，畫面下方會提示下一步。
   - 按 **Esc** 或右上角 ✕ 離開抽獎模式，回到設定或中獎清單（進行到一半的回合不會記錄）。
5. **匯出結果**：
   - 前往 **🏆 中獎清單** 頁面。
   - 點擊「匯出 CSV 名單」儲存中獎紀錄（欄位：獎項名稱、獎品內容、ID、中獎人員、抽出時間戳）。

## 📝 匯入獎項 CSV 範例格式

匯入的 CSV 檔案首行為標題列，內容格式如下：

| 名稱   | 獎品        | 數量 | 背景圖片連結                      | 允許重複中獎 | 動畫樣式 |
| :----- | :---------- | :--- | :-------------------------------- | :----------- | :------- |
| 特等獎 | MacBook Pro | 1    | https://example.com/gold-bg.jpg   | N            | 選堆     |
| 二等獎 | iPhone 15   | 5    | https://example.com/silver-bg.jpg | N            | slot     |
| 加碼獎 | 現金 1000   | 10   |                                   | Y            | 扭蛋機   |

- 第 5 欄「允許重複中獎」可省略（預設不允許），填 `Y`、`1`、`是`、`true` 視為允許。
- 舊版的「淘汰制」（`elimination`）會自動轉為「選堆」。
- 第 6 欄「動畫樣式」可省略（預設經典跳字），可填中文名稱或代碼：`classic` 經典跳字、`slot` 老虎機、`wheel` 幸運轉盤、`pile` 選堆、`flip` 翻牌、`countdown` 倒數揭曉、`gacha` 扭蛋機。

## ⚙️ 技術說明

- **亂數演算法**：中獎者一律由按鍵當下（選堆在開始時洗牌、翻牌在發牌時決定每張牌是誰），以 `crypto.getRandomValues`（密碼學安全亂數，拒絕取樣避免偏差）從「當下可用名單」均勻抽出；各種動畫只負責呈現結果，不影響誰中獎。動畫播完才寫入紀錄，中途切換頁面則該回合不記錄。匯出的「種子碼」為按鍵當下的時間戳，作為抽獎時間紀錄，無法用來重現結果。
- **狀態管理**：使用 Vue 3 的 `reactive` 與 `computed` 處理繁雜的名單排除與剩餘數量計算。
- **佈局技術**：使用 CSS Flexbox 與 `clamp()` 響應式字體，確保抽獎大字在各種螢幕尺寸都能完美呈現。

## ⚠️ 注意事項

- **清除緩存**：若要完全清空所有紀錄，請使用設定頁面底部的「🚨 全部重設」按鈕（名單、獎項、紀錄全部刪除）；若只想重新開始抽獎、保留名單與獎項，請使用「🧹 清空中獎名單」。
- **瀏覽器相容性**：建議使用最新版 Chrome、Edge 或 Safari 以獲得最佳動畫效果。
