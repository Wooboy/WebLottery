使用手冊

{{ t.label }}

一、快速開始

  1. 在「設定」頁的參與人員名單貼上名單（每行「ID,顯示名稱」）。
  2. 在獎項清單配置新增獎項，設定名額、抽獎模式與動畫樣式，可按「預覽」先試抽。
  3. 按右上角開始抽獎（全螢幕）進入抽獎畫面。
  4. 按 空白鍵 或 Enter 抽獎，依畫面下方提示進行；PageUp / PageDown 切換獎項。
  5. 抽完後按 Esc 離開，到「中獎清單」頁匯出 CSV。

所有資料都存在這台電腦的瀏覽器中，重新整理或關閉頁面不會遺失進度；不需要網路，也不需要伺服器。

二、參與人員名單

  • 每行一位，格式為「ID,顯示名稱」，例如 E001,王小明。ID 建議使用員工編號，不可重複；顯示名稱可以重複（同名不同人不會互相影響）。
  • 可用半形逗號、全形逗號或 Tab 分隔，可直接從 Excel 複製「員編、姓名」兩欄貼上；第一行若是「員編,姓名」等標題列會自動略過。
  • 格式有誤（缺少逗號、缺少名稱、ID 重複）時，該行行號標紅，名單下方列出錯誤行，點選即跳到該行；修正前無法開始抽獎。
  • 打亂順序：以安全亂數重排名單，只影響畫面上的排列順序，不影響中獎機率。
  • 名單鎖定：一旦有任何中獎紀錄，名單即鎖定不可修改；需要修改時請先按「清空中獎名單」。
  • 員編長度：有獎項使用「老虎機」動畫時，名單中每個 ID 都必須是此長度（3～5 碼）的英數字。

三、獎項設定

在「獎項清單配置」表格按「新增獎項」，每個獎項可設定：

欄位 說明
獎項名稱 / 獎品內容 顯示在抽獎畫面上方，例如「頭獎」「機車一台」。
名額 這個獎項要抽出幾位。
抽獎模式 名額大於 1 時可選：連續單抽（每按一次抽一位）或一次抽完（一次揭曉全部名額）。
允許重複中獎 不勾選（預設）：已中過其他「不允許重複」獎項的人不會再被抽到。
勾選：從全部名單抽選，適合加碼獎、紅包；中過此類獎項也不影響其他獎項的資格。
不論哪一種，同一獎項內都不會抽到同一人兩次。
動畫樣式 九種抽獎動畫擇一（見「抽獎動畫一覽」）。選「淘汰制」時可另外設定輪數。
預覽 以該獎項的設定模擬抽獎，可在預覽中切換樣式比較；結果不會寫入中獎紀錄。
背景圖 選填，抽獎時淡化鋪在背景。可填網址、相對於 index.html 的路徑（例如 img/頭獎.jpg），或直接貼上 Windows 路徑（例如 C:\圖片\頭獎.jpg）。左側顯示縮圖，讀取失敗會顯示紅字。
刪除 按垃圾桶圖示刪除，刪除前會再確認一次。

四、系統設定

  • 介面色系主題：紅、黑、藍、綠、金五種；底色固定深色，主題色用於點綴，金色保留給中獎者。
  • 現場效果：可分別開關「音效」與「中獎彩帶特效」。音效為程式合成，不需要音檔。
  • 清空中獎名單：刪除所有中獎紀錄，保留名單與獎項，可重新開始抽獎。
  • 全部重設：名單、獎項、中獎紀錄全部刪除，回到初始狀態。

五、設定檔匯出 / 匯入

  • 匯出設定檔：下載 抽獎設定_日期-時間.json，內容包含參與名單、獎項、系統設定與目前的中獎紀錄。
  • 匯入設定檔：選取匯出的 JSON 檔，確認後會覆蓋目前的名單、獎項、設定與中獎紀錄。
  • 事前準備：在個人電腦設定好後匯出，到會場電腦開啟 index.html 再匯入即可。
  • 抽到一半換電腦：在原電腦匯出、新電腦匯入，已中獎者不會被重複抽到，可直接接續下一個獎項。

背景圖若使用本機路徑，換電腦時需一併複製圖片並保持相同路徑。

六、抽獎畫面操作

按右上角「開始抽獎（全螢幕）」進入。畫面分為三段：上方為獎項名稱、獎品與剩餘名額；中間為抽獎動畫；下方為本獎項已中獎名單與操作提示。

按鍵 功能
空白鍵 / Enter 抽獎（開始 / 停止 / 下一步），依畫面下方提示操作
PageUp / PageDown 上一個 / 下一個獎項（抽獎進行中會鎖定）
Esc 離開抽獎畫面
  • 簡報筆的翻頁鍵即為 PageUp / PageDown，可直接用簡報筆操作。
  • 也可以點畫面右上角的左右箭頭切換獎項、點 ✕ 離開。
  • 獎項抽完時，右下角會出現「下一個獎項」按鈕。
  • 右下角「重抽」會清除本獎項的中獎紀錄並重新抽，按下後會先確認，不會離開全螢幕。
  • 切換獎項或離開再進入時，各獎項會保留最後的抽獎畫面。
  • 抽獎進行到一半離開（例如已發牌但還沒翻、淘汰到一半），再次進入時會回到原本的畫面繼續；離開時若動畫還在播放，會在背景播完並照常記錄。

八、中獎清單與匯出

  • 「中獎清單」頁籤列出所有中獎紀錄：獎項名稱、ID、中獎人員與抽出時間。
  • 按「匯出 CSV 名單」下載 CSV，可用 Excel 開啟（欄位：獎項名稱、獎品內容、ID、中獎人員、抽出時間戳）。

九、注意事項

  • 公平性：中獎者在按下按鍵當下以密碼學安全亂數，從當時可抽的名單中均勻抽出；動畫只負責呈現結果，不影響誰中獎。
  • 資料保存：資料存在瀏覽器中，清除瀏覽器資料會一併清除；建議活動前與抽獎中途適時匯出設定檔備份。
  • 全螢幕：瀏覽器不允許全螢幕時，會以視窗模式抽獎（按 Esc 離開）。
  • 瀏覽器：建議使用最新版 Chrome 或 Edge。
